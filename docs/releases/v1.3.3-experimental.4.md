# Iron Anvil Experimental 1.3.3 — easier mission setup

This update makes the existing co-op missions easier to create and understand. **[Stable 1.2](https://github.com/SkylerErcoli/DCSMissionGeneratorJamesIronDemonAnvil/releases/tag/v1.2.0) stays unchanged and separate.**

## What's changed

- **Quick setup:** one mission picker, your map/aircraft/pilots, target distance and three opposition presets. Detailed controls are under **Customize**. Unused controls stay hidden.
- **Better starting defaults:** nearby targets, daylight, clear weather, engines running in parking, recommended weapons and a friendly alternate. Balanced ground missions start without enemy fighters. Existing saved choices stay intact.
- **Clearer opposition:** Relaxed, Balanced and Challenging edit the existing threat/skill settings. Individual fighter and air-defense switches remain visible; manual changes show Custom. Relaxed removes optional threats, while ground troops remain armed.
- **Help where you fly:** F10 **Briefing / help** explains what to destroy and where to recover. Targets are marked automatically with required/optional labels; search missions show only their approximate area until check-in. The duplicate status entry is removed, and withdrawal status now explains the next step.
- **Cleaner planning:** essential Quick setup controls fit a 1024×700 window. Manual coordinates stay collapsed until needed. **New variation** previews another layout without saving a mission; Generate uses that plan. A pinned target clearly overrides distance.
- **Honest weapons information:** previews and browser briefings report actual loaded stores. An empty local payload preset gets a warning. Briefings lead with your job and keep technical details expandable.

Broken Relay, Supply Denial, Rolling Thunder and the original mission types remain available. This adds no new gameplay switches, required mods, accounts or aircraft packages.

## Download or update

### [Windows installer — Iron Anvil Experimental](https://github.com/SkylerErcoli/DCSMissionGeneratorJamesIronDemonAnvil/releases/download/v1.3.3-experimental.4/IronAnvil-Experimental-Setup-x64.exe)

Windows 10/11, 64-bit. Double-click the installer and open **Iron Anvil Experimental** from Start. Run it over the existing experimental installation; no uninstall is needed. No Python or command line is required. The installer is unsigned, so Windows may show an unrecognized publisher prompt.

[Portable ZIP](https://github.com/SkylerErcoli/DCSMissionGeneratorJamesIronDemonAnvil/releases/download/v1.3.3-experimental.4/IronAnvil-Experimental-Windows-x64.zip): choose **Extract All**, then open **IronAnvil.exe**. Keep the whole folder, including `_internal`.

## Checks and limits

The release pipeline checks the source/Lua suite, the mission matrix, **77 generated/reloaded missions in each packaged Windows app**, Quick setup and small-window behavior, an actual upgrade from published experimental 1.3.2, and stable 1.2 preservation. Reports and checksums are attached below.

**This preview has not been flown in DCS.** Terrain placement, road/ground AI, damage recognition and real multiplayer behavior still need flights. Check a new mission in Mission Editor before a group sortie.
