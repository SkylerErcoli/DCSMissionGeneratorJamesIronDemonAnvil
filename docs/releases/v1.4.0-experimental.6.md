# Iron Anvil Experimental 1.4.0 — varied geography, one portable EXE

This update fixes repetitive mission geography and removes installer overhead. **[Stable 1.2](https://github.com/SkylerErcoli/DCSMissionGeneratorJamesIronDemonAnvil/releases/tag/v1.2.0) remains unchanged.**

## What's changed

- **A single portable Windows EXE.** Save it anywhere and open it. No installer, extraction, Python or extra client mods. Update by closing the app and replacing the EXE; saved settings and missions remain separate.
- **Wider procedural variation.** Automatic planning now chooses compatible departures across map regions, samples eligible headings around the compass and varies distance within the selected sortie length. Classic standard missions no longer reuse a fixed target.
- **Better placement constraints.** Bundled offline coastline/lake/elevation data screen obvious water and steep terrain. Convoys seek approximate main-road corridors; operation sites must fit before accepting a target. Native DCS roads remain authoritative.
- **A useful offline map.** Shaded public terrain, lakes and major roads replace flat land coloring. No internet connection is needed. Preview airfield colors match the generated mission's ownership. This is public mapping, not DCS imagery.
- **Fresh automatic variations.** Preview still matches Generate, but its seed no longer becomes a permanent replay setting. The following automatic Generate chooses a new variation. Explicit replay seeds and map pins remain fixed and visibly identified.
- **Coherent local scenarios.** Friendly recovery fields and support stay behind the operation; automatic alternates are nearby. Explicitly selected isolated departures can require a longer alternate, explained in the briefing. Support orbits and hostile air staging remain inside planner bounds. Air starts and route altitude handling account for approximate terrain.
- **More compound variety and joining help.** HESCO, concrete blast screens, mixed screens and optional watchtowers vary compounds. Fortified lines keep their staggered sandbags. Joining pilots receive a private briefing; F10 help remains available.
- **Faster release checks.** One native portable-app probe replaces duplicate installed-app tests and older-installer downloads. Source checkpoints do not compile Windows binaries. A few focused checks during development precede one finished Windows build.

In a saved 1,800-plan comparison (300 seeds per map for classic and convoy-operation plans), every map/mode produced 300 distinct targets and all eight heading sectors with no planning failures. Classic departures increased from one per map to **21 Caucasus, 72 Syria and 85 Germany** in that sample. Compatibility and terrain legitimately constrain individual departures/directions.

## [Download IronAnvil-Experimental.exe](https://github.com/SkylerErcoli/DCSMissionGeneratorJamesIronDemonAnvil/releases/download/v1.4.0-experimental.6/IronAnvil-Experimental.exe)

Windows 10/11, 64-bit. Save the file and double-click it. The executable is unsigned, so Windows may show an unrecognized publisher prompt.

For an existing portable copy, close it and replace the EXE. If you used an earlier installer, open the new downloaded EXE directly; your old Start-menu shortcut still points to the older installed app. Experimental preferences are retained. Stable 1.2 keeps its own settings and download channel.

## Checks and remaining gaps

The pipeline checks the source/Lua suite and native portable executable, including **25 generated/reloaded missions**, offline relief on every map, actual saved ownership/navigation, a read-only application folder, no Python on PATH, paths with spaces, and settings/mission preservation during EXE replacement. Reports and the checksum are attached below.

The [original-request audit](https://github.com/SkylerErcoli/DCSMissionGeneratorJamesIronDemonAnvil/blob/experimental/docs/experimental/ORIGINAL-REQUEST-AUDIT.md) distinguishes completed work from missing or superseded features. Forward FARPs, dedicated WWII force sets, measured wall calibration, per-player kill export and campaign persistence remain outside this release.

**No real DCS flight has been performed here.** Public elevation/roads cannot certify DCS buildings, trees, slopes or AI routes. Inspect new locations in Mission Editor; flight-test support, roads and multiplayer before a group night. Existing `.miz` files keep their embedded controller. Generate a new mission for the new behavior; old seeds can produce different layouts in the new generator version.
