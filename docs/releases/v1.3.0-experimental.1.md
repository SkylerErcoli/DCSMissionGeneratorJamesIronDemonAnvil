# Iron Anvil Experimental — first co-op preview

A separate playground for richer missions with your existing squadron. **Stable 1.2 remains available and unchanged.** This preview installs beside it with its own settings and mission folder.

## New ways to fly together

- **Operation Broken Relay:** disable two of three fuel tanks. Take out a command structure first to delay the ground response by six minutes. Choose either site first.
- **Operation Supply Denial:** disable an ammunition structure. Destroy a bonus fuel tank before dispatch to cancel the ground response.
- **Finite enemy response:** one force waits at a staging area and responds after the first damage to an objective. It travels toward the main site; you can intercept it or finish and withdraw. No endless waves.
- **Shared goals and debrief:** optional objectives earn bonuses, scenery does not block victory, and every surviving participating pilot must return home. Shared scoring rewards objectives and recovery.

All pilots can fly **the same aircraft type**. Choose the aircraft and map your group already owns. No extra client mods, scripting hooks, accounts or paid services are required. The five original mission types are still available through **Classic single mission**.

## Easier planning and replay

- Close-to-base, standard and longer automatic target distances, adjusted for helicopters. A pinned target always takes priority.
- A mission kneeboard with objectives, coordinates, radios and a route schematic.
- A readable **Mission briefing** button that opens a local page with the same information.
- Named squadron presets, portable settings export/import, and loading settings from a previous `.miz`.
- **Repeat last mission** restores its settings and variation number. Use another number for a fresh layout.
- Dark/light mode, all 472 catalogued airfields/helipads, weather choices, protected support and independent CAP/air-defense switches are retained.

This preview uses a separate installation identity, settings/cache location and mission folder. The stable app's updater will not install it. **Experimental downloads** inside this app opens this dedicated page. Future experimental installers can be run over this experimental copy without uninstalling.

## Before your first sortie

**This is an experimental preview, not a DCS flight-tested release.** Automated tests check generated archives and native Lua API behavior, and Windows packaging checks the real frozen/installed programs alongside published 1.2.0. Terrain placement, roads/ground AI, static damage recognition and in-simulator kneeboard display still need live DCS playtesting.

Check the mission in the DCS Mission Editor before a group flight. Start with enemy CAP and air defenses off to learn the objectives, then increase opposition as desired. F10 → Iron Anvil includes operation status, target marks, response staging and vectors home.
