# Iron Anvil Experimental 1.3.4 — cold starts and target assistance

More help in the cockpit, with the same simple mission setup. **[Stable 1.2](https://github.com/SkylerErcoli/DCSMissionGeneratorJamesIronDemonAnvil/releases/tag/v1.2.0) remains separate and unchanged.**

## What's changed

- **Engines off by default:** new installs and **Use recommended setup** now start cold in parking. Upgrading preserves saved preferences; use that button to switch an existing hot-start setup to cold. Hot, runway and air starts remain available under Customize.
- **Optional target smoke:** **F10 → Iron Anvil → Target assistance → Smoke target (orange)** provides a visual cue for ground targets. An airborne teammate must be within 15 km; the team shares a five-minute cooldown. Search missions require recon confirmation first. Smoke marks the convoy's current position when requested; moving vehicles can leave it behind. This is visual help, not a JTAC or laser.
- **Cockpit-friendly coordinates:** live target reports now include decimal degrees, degrees/decimal minutes, degrees/minutes/seconds and DCS MGRS. Coordinate rounding carries correctly into the next degree.
- **A separate navigation kneeboard:** public coordinates, home/alternate ATC frequencies and available runway directions, also shown in the browser briefing. Search missions show only their approximate search area. Runways are listed directions rather than an assigned clearance.
- **Clearer vectors and radio menu:** bearings identify true north, with an explicitly labeled grid fallback. Position, bearing and smoke commands are grouped under Target assistance to keep the main F10 menu short.

These ideas draw on [documented features in BriefingRoom and Liberation](https://github.com/SkylerErcoli/DCSMissionGeneratorJamesIronDemonAnvil/blob/experimental/docs/experimental/NAVIGATION-RESEARCH.md). No new setup switches, required mods, accounts or aircraft packages are added.

## Download or update

### [Windows installer — Iron Anvil Experimental](https://github.com/SkylerErcoli/DCSMissionGeneratorJamesIronDemonAnvil/releases/download/v1.3.4-experimental.5/IronAnvil-Experimental-Setup-x64.exe)

Windows 10/11, 64-bit. Run the installer over your experimental copy, then open **Iron Anvil Experimental** from Start. No uninstall, Python or command line is needed. The installer is unsigned, so Windows may show an unrecognized publisher prompt.

[Portable ZIP](https://github.com/SkylerErcoli/DCSMissionGeneratorJamesIronDemonAnvil/releases/download/v1.3.4-experimental.5/IronAnvil-Experimental-Windows-x64.zip): choose **Extract All**, then open **IronAnvil.exe**. Keep the complete folder, including `_internal`.

## Checks and limits

The pipeline checks the source/Lua suite, mission matrix, **77 generated/reloaded missions in each packaged Windows app**, both kneeboard pages, search privacy, cold starts, saved hot-start preferences, actual upgrade from experimental 1.3.3 and stable 1.2 preservation. Reports and SHA-256 checksums are attached below.

**No real DCS flight has been performed here.** Smoke rendering, catalogue radios, terrain, roads, AI, kneeboard display and multiplayer behavior still need in-simulator checks. Inspect a new mission in Mission Editor before a group sortie.
