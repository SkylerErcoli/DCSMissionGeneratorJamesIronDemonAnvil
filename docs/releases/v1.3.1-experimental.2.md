# Iron Anvil Experimental — convoys, recovery and intelligence

More choices for a co-op evening with the aircraft and maps your group already owns. This is the **second experimental preview**. [Stable 1.2](https://github.com/SkylerErcoli/DCSMissionGeneratorJamesIronDemonAnvil/releases/tag/v1.2.0) stays available, unchanged, and installed separately.

## What's new since the first preview

- **Operation Rolling Thunder:** hunt a moving supply convoy. Stop two of its three cargo trucks before delivery for bonus points. If supplies arrive, a still-preparing ground response mobilizes sooner; the main objective remains achievable. Destroying bonus fuel support before dispatch cancels the response. Escorts and scenery never become mandatory cleanup targets.
- **Recover at a friendly alternate:** choose home-only recovery or approve a suitable friendly alternate. Both bases have fuel and ammunition, and F10 can give vectors. Jets get a runway; helicopters can use compatible helicopter bases.
- **Withdraw with a useful result:** agree over comms, propose withdrawal through F10, and confirm within 30 seconds. A teammate can cancel the proposal. Recover every survivor for a partial debrief with proportional objective credit. Enemies stay active; completing the main objective before recovery can still earn full success.
- **Search-area intelligence:** optionally start with an approximate search area. Keep an airborne teammate inside for 45 continuous seconds, then request F10 **Recon check-in** to share target coordinates and earn a small team bonus. Exact targets are withheld from the briefing, navigation waypoints, planner and initial F10 marks. Enemy ground symbols are hidden. This is a radio-intelligence game rule, not simulated aircraft sensor recognition; you can still find targets visually.
- **Preview before generating:** see home, alternate, known targets and staging areas, or the search area, on the map. Preview chooses a variation number if needed so Generate uses the same plan. Changing settings clears the preview. Nearby labels use separate callouts; **Fit mission** brings the plan back into view.
- **Updated briefings and replay:** kneeboards, local briefings, saved presets and shared settings include the new choices. Optional targets receive a navigation waypoint when precise intelligence is selected.

Broken Relay, Supply Denial, classic missions, dark/light mode, nine weather choices, all 472 catalogued airfields/helipads, protected tanker/AWACS support and independent CAP/air-defense switches remain available. Everyone can keep flying the same aircraft type. No extra client mods or scripting changes are required.

## Download and update

### [Windows installer — Iron Anvil Experimental](https://github.com/SkylerErcoli/DCSMissionGeneratorJamesIronDemonAnvil/releases/download/v1.3.1-experimental.2/IronAnvil-Experimental-Setup-x64.exe)

Windows 10/11, 64-bit. Double-click the installer, then open **Iron Anvil Experimental** from Start. **Already have the first experimental preview? Run this installer over it; no uninstall is needed.** The installer is unsigned, so Windows may show an unrecognized publisher prompt. No Python or command line is needed.

[Portable ZIP](https://github.com/SkylerErcoli/DCSMissionGeneratorJamesIronDemonAnvil/releases/download/v1.3.1-experimental.2/IronAnvil-Experimental-Windows-x64.zip): choose **Extract All**, then open **IronAnvil.exe**. Keep the entire folder, including `_internal`.

Experimental installs and updates its own copy, settings and mission folder. The stable app's updater does not offer previews. Only the mission creator needs this generator; friends need DCS and the selected map/aircraft modules.

## Validation and first flight

Release checks exercise **73 generated/reloaded missions in each Windows frozen and installed app**, including 30 cooperative-operation cases, six search cases and twelve alternate-recovery cases. The desktop probe renders all maps in both themes, previews a search mission and reloads settings. Packaging also verifies the published old experimental installer, upgrades it in place, and checks stable 1.2 still works after experimental uninstall. The validation reports are attached below with the downloads and checksums.

**This preview has not been flown in DCS.** Automated archive and Lua tests cannot establish terrain clearance, road/ground AI behavior, static damage recognition, multiplayer timing or in-simulator kneeboard display. Review your first mission in the Mission Editor and start with opposition off while learning the new rules.

F10 → **Iron Anvil** contains status, target marks, search check-in when enabled, recovery vectors and the optional team withdrawal procedure.
